
## Objetivo (1 frase)
- Soportar interacciones diferidas basadas en tareas: crear, consultar por sondeo, suscribirse por SSE y cancelar, tanto en API nativa como en fachada A2A.

## In (scope)
- S21-T01 a S21-T06.

## Out / No-goals del sprint
- No hay cola por instancia: si un agente está ocupado, se rechaza la interacción.
- No hay garantías tras reinicio de SAD: las tareas en memoria se pierden y el cliente debe volver a pedir o reintentar.
- No hay “repetición” (replay) de eventos de suscripción tras reconexión: la suscripción empieza con un snapshot del estado actual y continúa con actualizaciones a partir de ahí.
- No se implementan notificaciones salientes (webhook) de A2A.
- No se implementa listado de tareas (`ListTasks`) en A2A.

## Dependencias
- Depende de: S14 (timeouts), S15 (stop/delete semantics), S09 (SSE/backpressure), S11 (status/logs), S13 (gateway/auth).
- Bloquea: soporte robusto de ejecuciones largas sin mantener conexiones abiertas.

## Gates (con pass/fail)
- S21-G1: make ci
  - Comando: make ci
  - Pass: `gleam format --check src test`, `gleam test`, `gleam test --coverage` en orden y sin errores
  - Fail: cualquier comando con exit code != 0
