## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Se abre un port y se reciben lineas completas del child.
  - Cerrar stdin termina el child en tiempo razonable.
  - Enviar {"t":"stop"} termina el child.
  - Si el child ignora SIGTERM, el wrapper escala a SIGKILL.
- Casos incorrectos:
  - Binario inexistente termina con exit != 0.
  - Salida sin salto de linea produce infra_error.
  - Linea > max_runner_event_bytes produce infra_error.
  - Salida total > max_stdout_bytes produce infra_error y stop.
  - Timeout de lectura no mata el proceso.
