# S23-T02 - Global params defaults with `params.` namespace

## Sprint
- Sprint: S23
- Capa: Config + Params
- Riesgo: Medio
- Gate: Sí

## Objetivo (1 frase)
- Añadir defaults globales para parámetros de agentes usando `[params]` y claves `params.*` sin colisionar con configuración del sistema.

## SSOT (obligatorio)
- `docs/arquitectura/config.md` - config model and defaults
- `src/saar/config_loader.gleam` - parsing/validation
- `src/saar/types/config.gleam` - config value lookup
- `src/saar/params.gleam` - param resolution

## Inputs (obligatorio)
- Config keys usadas:
  - `[params]` map con valores simples (string/int/float/bool/list)
- Supuestos:
  - Los perfiles que quieran defaults globales usan `key = "params.<name>"`.

## Outputs (obligatorio)
- Codigo:
  - `types/config.gleam`: añadir `params: Dict(String, Value)` en `SaarConfig`.
  - `config_loader.gleam`: aceptar top-level `params`.
  - `types/config.gleam`: resolver `params.<name>` contra `SaarConfig.params`.
  - `params.gleam`: sin cambios (usa `config_values`).
- Tests (inventario exacto):
  - `test/unit/config_loader_test.gleam`:
    - `params_table_is_accepted`
    - `params_table_rejects_unknown_types`
  - `test/unit/config_values_test.gleam`:
    - `config_value_resolves_params_namespace`
    - `config_value_does_not_override_system_keys`
  - `test/unit/params_resolution_test.gleam`:
    - `config_param_reads_params_namespace`
    - `config_param_missing_params_namespace_errors`

## Limites y defaults (obligatorio)
- Los valores de `[params]` son opcionales.
- Si falta `params.<name>` y no hay default en el perfil → error.

## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Un perfil con `key = "params.model"` toma el valor desde `[params]`.
  - Claves del sistema (`server.port`, `limits.*`) siguen intactas.
  - `params.*` no puede sobreescribir config del sistema.
- Casos incorrectos:
  - `params` con tipos no soportados se acepta.
  - `params.*` resuelve contra claves del sistema.

## Semántica de errores (obligatorio)
- `InvalidValue(key: "params.<name>")` para tipos no soportados.

## Evidence reproducible (obligatorio)
- `gleam test` con exit 0.

## No-goals (obligatorio)
- No soportar secretos en `[params]`.
- No cambios en perfiles existentes (solo nuevos que quieran usar defaults globales).
