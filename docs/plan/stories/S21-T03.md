## Outputs (obligatorio)
- API nativa:
  - `POST /agents/:instance_id/interact`
    - Si `response_mode=sync`: comportamiento actual (200 o 504 según timeout)
    - Si `response_mode=stream`: comportamiento actual SSE de interacción
    - Si `response_mode=deferred`:
      - crear tarea (idempotente por `context.trace_id`)
      - responder `202` con `{task_id, state, instance_id}`
  - `GET /tasks/:task_id`
    - 200 con estado y `result`/`error` cuando sea terminal
    - 404 si no existe
  - `DELETE /tasks/:task_id`
    - Si está `running`: cancelar (estado terminal `cancelled`)
    - Si es terminal: borrar (y posteriores `GET` devuelven 404)
- Mapeo de errores:
  - Busy: `422` con ProblemDetails `agent_error` (mantener semántica actual)
  - Cancelación: estado terminal `cancelled` (no `failed`)

## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Un cliente puede iniciar una interacción larga sin mantener conexión abierta.
  - La respuesta final se recupera por `GET /tasks/:task_id`.
  - `DELETE /tasks/:task_id` permite cancelar y borrar.
- Casos incorrectos:
  - Responder `failed` cuando SAAR cancela.
