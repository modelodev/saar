## Acceptance Criteria (obligatorio)
- Casos correctos:
  - stop no borra artifacts ni workspace.
  - delete purga artifacts y workspace (best-effort) y libera port.
  - cleanup falla -> se devuelve error pero artifacts quedan purgados.
  - stop/delete durante interacción en curso termina el worker y el cliente ve "cancelled".
  - delete sobre instancia inexistente → OK (idempotente).
- Casos incorrectos:
  - delete deja artifacts accesibles.

## Semantica de errores (obligatorio)
