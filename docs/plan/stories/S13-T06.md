## Acceptance Criteria (obligatorio)
- Casos correctos:
  - /sys/agents create requiere instance_id.
  - Request minimo: {profile_id, instance_id, init_params?} con escalares.
  - Respuestas incluyen a2a_base_url por instancia.
  - /sys/profiles devuelve ProfileMeta (no perfil completo).
  - /sys/reload-profiles devuelve status + count + lista de ids.
  - /sys/reload-profiles mantiene el set anterior si hay error de IO/JSON.
  - logs/stream envia replay y luego live, con keep-alive.
  - SSE logs incluye ts_ms, line, trace_id.
- Casos incorrectos:
  - /sys/agents usa instance_id opcional.
  - instance_id invalido => bad_request.
  - GET /sys/agents/:instance_id (sin /status).
  - /sys/agents/:instance_id ambiguo (no debe ocurrir con unicidad global).

## Semantica de errores (obligatorio)
- ErrorKind esperado:
  - bad_request para body invalido
  - agent_error para Busy/Stop errors
- ProblemDetails esperado:
  - 401 sin token
  - 404 si instance_id no existe
  - 409 en create si instance_id ya existe
