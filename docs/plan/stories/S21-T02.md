## SSOT (obligatorio)
- `docs/arquitectura/README.md` - regla de modularización
- `docs/plan/limits.md` - tabla de config y defaults (SSOT)
- `docs/arquitectura/actores.md` - stop/delete y cancelación

## Inputs (obligatorio)
- Config keys usadas (con defaults esperados):
  - `limits.task_retention_ms` (default 604800000)
  - `limits.max_tasks` (default 10000)
  - `limits.max_task_result_bytes` (default 262144)
- Supuestos:
  - Las tareas viven en memoria y se pierden tras reinicio.
  - El cliente es responsable de descargar artefactos si los necesita; SAAR no da garantías tras reinicio.

## Outputs (obligatorio)
- Código:
  - Actor `TaskStore` (memoria) con API para:
    - crear tarea (id = `trace_id` cuando se proporciona)
    - leer tarea
    - transicionar estados y almacenar resultado/error
    - cancelar tarea
    - borrado explícito (`DELETE /tasks/:id`) + recolector por retención
  - Límite de tamaño del resultado almacenado (`max_task_result_bytes`)
  - Límite de número de tareas (`max_tasks`)
- Config:
  - Añadir keys a `docs/plan/limits.toml` + regenerar `docs/plan/limits.md`
- Tests (inventario exacto):
  - `test/unit/task_store_test.gleam`:
    - `store_roundtrip_get`
    - `gc_removes_old_terminal_tasks`
    - `max_tasks_limit_enforced`
    - `max_task_result_bytes_enforced`

## Límites y defaults (obligatorio)
- `limits.task_retention_ms`: 604800000
- `limits.max_tasks`: 10000
- `limits.max_task_result_bytes`: 262144

## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Se puede consultar una tarea completada sin mantener la conexión original.
  - El store no crece sin límite (max_tasks + GC por retención).
- Casos incorrectos:
  - Guardar resultados sin límite y provocar OOM.

## Semántica de errores (obligatorio)
- ErrorKind esperado:
  - `infra_error` si falla la gestión interna de tareas (p.ej. límite excedido con motivo explícito).

## Evidence reproducible (obligatorio)
- Comandos:
  - `gleam test`
- Esperado:
  - Exit code 0

## No-goals (obligatorio)
- Persistencia en disco / recuperación tras reinicio.
