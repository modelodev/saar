## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Ruta /agents/:instance_id/ui/* se proxifica sin rewrite adicional.
  - Se inyectan headers X-Forwarded-* y X-SAAR-Instance-Id/Profile-Id.
  - Respuesta grande se corta en max_http_response_bytes y retorna 502.
  - No se agregan headers Access-Control-*.
  - Request sin API key → 401.
  - El upstream se deriva solo del estado del agente (host/port/scheme no controlables por el cliente).
  - Errores de proxy no filtran secretos en Problem Details.
- Casos incorrectos:
  - Se forwardea Authorization o Cookie.
  - Se permite path traversal con `..` o `%2e%2e`.
  - Se permite Upgrade websocket.

## Semantica de errores (obligatorio)
- ErrorKind esperado:
  - infra_error cuando upstream falla
- ProblemDetails esperado:
  - 400 con code "websocket_not_supported"
  - 401 sin token
  - 502 si upstream excede limite o falla
