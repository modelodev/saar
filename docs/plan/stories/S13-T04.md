## Acceptance Criteria (obligatorio)
- Casos correctos:
  - Con API key valida, endpoints /sys responden.
  - /health y /health/ready no requieren auth.
  - /health/ready retorna 200 solo si profiles_count > 0.
- Casos incorrectos:
  - Si falta auth.api_key, el server arranca (debe fallar en S13-T02).
  - /health/ready retorna 200 con profiles vacios.

- ProblemDetails esperado:

  - 503 en /health/ready cuando profiles_count == 0
