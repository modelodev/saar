## Acceptance Criteria (obligatorio)
- Casos correctos:
  - "./a/./b" => "a/b".
  - "a//b" => "a/b".
  - "a/" => "a".
  - symlink a /etc/passwd dentro del workspace => error.
- Casos incorrectos:
  - "../x" y "a/../../b" => Error(PathTraversalDetected).
  - "" o "." o "////" => Error(EmptyPath).
  - "/etc/passwd" => Error(AbsolutePathNotAllowed).
  - "a\0b" => Error(InvalidCharacter).
